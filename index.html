JavisLink

JavisLink is a shop-floor translator. The PC on your network is the translation server. The phone does not translate on its own. On the same Wi-Fi, type the pair code from the shop PC and join that conversation.

Download the Android APK

Install on the phone

  1. Download javislink.apk.
  2. Allow install from unknown sources when Android asks.
  3. Open the APK and install JavisLink.
  4. On the PC, from the JavisLink folder, run npm run local:lan. That serves the local server on port 8080.
  5. On the PC, open http://127.0.0.1:8080/manage and read the 6-digit pair code.
  6. On the phone, on the same Wi-Fi, open JavisLink and type that code plus the shop PC address shown on the manage page.

Hold the on-screen button to talk. On Android, Volume Up does the same thing while JavisLink is open. Letting go sends what you said to the PC. A very short tap cancels.
