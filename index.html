JavisLink

JavisLink is a shop-floor translator. The PC on your network is the translation server. The phone does not translate on its own. It scans the QR code that PC already shows and joins that conversation.

Download the Android APK

Install on the phone

  1. Download javislink.apk.
  2. Allow install from unknown sources when Android asks.
  3. Open the APK and install JavisLink.
  4. On the PC, from the JavisLink folder, run npm run local:lan. That serves the local server on port 8080.
  5. Copy certs/javislink.crt onto the phone and install it as a CA certificate so the phone trusts the PC.
  6. Open JavisLink, tap Scan, and scan the QR on the PC. The other phone scans that same link.

Hold the on-screen button to talk. On Android, Volume Up does the same thing while JavisLink is open. Letting go sends what you said to the PC. A very short tap cancels. iPhone uses the on-screen button.
